# The Great Potato Space Program

Each launch attempt holds direct references to its `Potato` and `Launcher` objects instead of just their IDs, and `Potato` is an abstract superclass with four subclasses (Fingerling, Purple, Russet, Yukon Gold). While reading the CSV files, `CsvReader` uses one HashMap from potato ID to potato and another from launcher ID to launcher to look up those objects for each attempt. The scoring formulas live in the four potato subclasses, which implement the `IScore` interface, and `LaunchAttempt` calls the score through that interface. `ReportWriter` groups the attempts in TreeMaps so the reports come out sorted by ID, and `LaunchAttempt` implements `Comparable` to rank the best flights. Run `Main` from the project root to read `input/` and write the five reports to `output/`.
